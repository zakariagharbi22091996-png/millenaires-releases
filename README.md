# Millénaires

Jeu de stratégie en temps réel, de l’âge de pierre à l’âge nano.

**[Télécharger la dernière version](../../releases/latest)** : prends `Millenaires-win64.zip`, décompresse-le où tu veux et lance `Millenaires.exe`. Le jeu se met ensuite à jour tout seul (bouton « Mettre à jour » sur l’écran titre).

Windows peut afficher « Windows a protégé votre ordinateur » (le jeu n’est pas signé) : **Informations complémentaires** puis **Exécuter quand même**.
